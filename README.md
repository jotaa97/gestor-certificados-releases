# Gestor de Certificados — instaladores

Este repositorio solo contiene los instaladores de Windows del Gestor de
Certificados, publicados en la pestaña **Releases**. El código fuente está en
un repositorio privado.

- `GestorCertificados-Setup-<versión>.exe`: instalador (por usuario, sin
  administrador). Antes de ejecutarlo, botón derecho → Propiedades →
  «Desbloquear».
- `GestorCertificados-<versión>-win.zip`: versión portable, para PCs con el
  Control inteligente de aplicaciones activado. Extraer y ejecutar
  `Gestor de Certificados.exe`.

La aplicación instalada comprueba aquí si hay versión nueva y se actualiza sola.
